# 风格锚点库（Style Anchor Library）

> 供 `image-prompt-architect` SKILL.md 步骤 2「绘本上下文注入」引用。
> 本库是**多风格通用模板库**，属「通用能力」而非某系列/项目专属画风。
> `context.art_style` 命中下方任一命名风格时，须**完整展开**该锚点的正向词 + 禁止项，禁止精简/压缩。

---

## 使用规则（image-prompt-architect 必须遵守）

1. **匹配**：`context.art_style` 与某锚点的「命名标识」或其别名精确/包含匹配时，命中该锚点。
   - 资产前置素材图模式由调用方**固定传入「黑白线条手绘素描」**并命中锚点「黑色线条手绘素描」，本库不另立独立锚点。
2. **展开**：命中后，将该锚点的「完整展开段落」作为 prompt 的**风格行原文**注入，不删减、不改写、不压缩（风格行长度不是负担，是质量保证）。
3. **修改/重试**：任何修改或重试模式（含 `context.modification_request`）下，风格行**强制复用锚点原文**，不得重写——重试不是重新创作。
4. **参考提取模式**：存在参考图时，风格行之后**显式追加**一句：「颜色与质感由风格锚点主导，参考图仅提取角色造型特征，不搬运参考图的色彩与质感」。
5. **未命中**：`context.art_style` 未命中任何锚点时，按原逻辑直接使用 `context.art_style` 文本，不强制套用本库。

## 锚点清单

### 1. 黑色线条手绘素描

- **命名标识**：黑白线条手绘素描 / 黑色线条手绘素描 / 素描风 / 手绘素描 / 单色素描 / pencil sketch
- **正向锚点词**：铅笔素描线条质感；线条有轻重粗细变化；深灰调交叉影线阴影；单色黑或深灰表现；大量留白
- **禁止项**：彩色填充、饱和色、plush toy 毛绒质感、水彩油画上色、渲染感
- **完整展开段落**：

  > 艺术风格：黑色线条手绘素描风格。铅笔素描线条质感，线条有轻重粗细变化，深灰调交叉影线阴影。单色黑或深灰表现，大量留白。禁止任何彩色填充，禁止饱和色，禁止 plush toy 毛绒质感，禁止水彩油画上色风格，禁止渲染感。

### 2. 水彩童话风

- **命名标识**：水彩童话风 / 水彩风 / 水彩质感 / watercolor
- **正向锚点词**：柔和暖色调；水彩晕染质感；通透的色彩过渡；圆润柔和的轮廓线；轻盈笔触
- **禁止项**：重彩厚涂、生硬描边、暗黑压抑色调、写实渲染
- **完整展开段落**：

  > 艺术风格：水彩童话风。柔和暖色调，水彩晕染质感，通透的色彩过渡，圆润柔和的轮廓线，轻盈笔触。禁止重彩厚涂，禁止生硬描边，禁止暗黑压抑色调，禁止写实渲染。

### 3. 毛绒玩偶风

- **命名标识**：毛绒玩偶风 / 毛绒风 / plush toy / 玩偶质感
- **正向锚点词**：毛绒织物质感；圆润饱满的造型；柔和暖光；可爱温和的表情；柔和低饱和配色
- **禁止项**：写实皮肤质感、锐利边缘、冷峻色调、塑料反光
- **完整展开段落**：

  > 艺术风格：毛绒玩偶风。毛绒织物质感，圆润饱满的造型，柔和暖光，可爱温和的表情，柔和低饱和配色。禁止写实皮肤质感，禁止锐利边缘，禁止冷峻色调，禁止塑料反光。

### 4. 扁平矢量风

- **命名标识**：扁平矢量风 / 扁平风 / 矢量风 / flat vector
- **正向锚点词**：扁平色块填充；简洁几何造型；清晰干净的轮廓线；高明度配色；无渐变
- **禁止项**：写实光影、复杂纹理、立体渲染、渐变过渡、透视纵深
- **完整展开段落**：

  > 艺术风格：扁平矢量风。扁平色块填充，简洁几何造型，清晰干净的轮廓线，高明度配色，无渐变。禁止写实光影，禁止复杂纹理，禁止立体渲染，禁止渐变过渡，禁止透视纵深。

## 扩展说明

新增风格时，在下方追加一个「### N. 风格名」区块，须包含四部分：`命名标识`（含别名）、`正向锚点词`（4–6 个）、`禁止项`、`完整展开段落`（可直接注入 prompt 的风格行原文）。
