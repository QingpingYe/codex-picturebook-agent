# 量化基准表：儿童绘本文字创作对标

> 定位：绘本文字创作的**数值护栏层**。用法：先按目标体裁定位基准区间，写完后自测对标。
> 配套：`craft-principles.md`（方法论）｜`technique-cards.md`（技法细则）｜`preflight-checklist.md`（自检）
>
> **基准性质**：本表数值为**体裁级通用基准**——来自经典作品的文学工艺统计，跨项目恒定，供创作时"看齐"参考。
> 凡涉及具体项目的页数、蓝思、词量上限等参数，一律以运行时加载的项目内容规格为准；本表不提供也不覆盖项目参数。
> 本表末尾的「机读基准块」是 `craft-benchmark-check` 技能的阈值来源。

---

## 一、总览基准

| 指标 | 基准区间 | 创作含义 |
|---|---|---|
| 总页数 | 22–40 页（主流） | >64 页即进入桥梁书/章节书形态 |
| 有字页占比 | 约 75%–85% | 极简型可低至 30% |
| 无字页 | 0–6 页 | 无字页是画面接管点，置于情绪顶点 |
| 全书正文字符 | 1500–6500（绘本核心区间） | >10000 即桥梁书 |
| 平均句长 | 3.5–13 词/句（按年龄分档，见 §5） | 3-5 岁 ≤8；5-8 岁 8-13；超过 15 已是儿童文学腔 |
| 副歌句式种数 | 韵文/认知类 ≥3 种 | 出现 ≥3 种重复句式是韵文书的结构信号 |
| 开篇复现书名 | 韵文书标配；纯叙事书可免 | 过半经典作品在第一正文页复现书名关键词 |
| 结尾-开头回环 | 循环类结构书应强回环 | 线性叙事书不需要，但结尾须"回归日常" |

## 二、三种形态分档（按全书字符量）

| 形态 | 字符区间 | 代表样本 | 句长特征 | 创作定位 |
|---|---|---|---|---|
| **极简型** | <1200 | Goodnight Moon(667)、They All Saw a Cat(972)、别让鸽子开巴士(997)、The Pigeon Finds a Hot Dog!(1058) | 两极分化：超短句（3-5 词）或单句跨页 | 2-4 岁；每页一个镜头；认知/互动/睡前 |
| **标准绘本** | 1500–6500 | The Gruffalo(4244)、Giraffe Problems(3569)、Where the Wild Things Are(2010)、The Snowy Day(3209) | 8-12 词/句 | 3-8 岁主流叙事绘本 |
| **桥梁书** | >10000 | Frog and Toad(11762)、Curious George(12862)、The Little House(12399) | 6-13 词/句，段落化 | 5-9 岁独立阅读；分章；插图半页节奏 |

|---|---|---|---|---|---|

## 四、结构与节奏基准

### 4.1 副歌强度分级（最高频重复行出现次数）

| 等级 | 次数 | 例证 | 效果 |
|---|---|---|---|
| 微弱 | 3–4 | 《The Gruffalo》 | 节奏锚点，不构成结构 |
| 标准 | 5–9 | 《我们要去捉狗熊》《Brown Bear, Brown Bear》《炫酷乔》 | 儿童两轮后可跟读 |
| 强结构 | 10–14 | 《穿外套的山羊》 | 书名级副歌，几乎每页开头 |

### 4.2 无字页位置惯例

- **高潮/狂欢段**：《Where the Wild Things Are》——rumpus 狂欢段连续无字跨页
- **情绪跌落段**：《浴缸小人》——孩子失踪后连续 3 个无字页
- **认知展示段**：《They All Saw a Cat》——视角画面全接管
- **睡前书例外**：《Goodnight Moon》仅 2 个无字页——安抚型全书节奏均匀，不制造静默

### 4.3 钩子与回环基准

- 开篇复现书名：韵文类（副歌即书名）应 100%；纯叙事类可 0。
- 强回环（结尾-开头实词重合显著）适用于「循环打破」结构：如《If You Give a Mouse a Cookie》《我们要去捉狗熊》《爱心树》。
- 线性叙事（如《好奇的乔治》《极地特快》）不需要强回环，但结尾须有「回归日常」句式。

## 五、语言难度基准

### 5.1 平均句长分档

| 档位 | 词/句 | 例证 | 适用年龄 |
|---|---|---|---|
| 超短 | 3.5–5.5 | 《The Pigeon Finds a Hot Dog!》(3.7) | 2-4 岁 |
| 短 | 6–8 | 《Llama Llama Red Pajama》(6.6)《凯蒂和大雪》(6.6) | 4-6 岁 |
| 中 | 8–12 | 《The Gruffalo》《Where the Wild Things Are》《In My Heart》 | 5-8 岁 |
| 长 | 12–15 | 《The Little House》(12.0)《Goodnight Moon》(12.2) | 6-8 岁/亲子共读 |
| 超长 | >15 | 《The Polar Express》《The Tale of Peter Rabbit》 | 亲子共读 |

### 5.2 句式语气基准

- 问句驱动：互动书用连续 What if 焦虑问句堆叠（例：《The Pigeon HAS to Go to School!》连续 7 问）；认知书每页一问（例：《Brown Bear, Brown Bear, What Do You See?》）。
- 感叹句：互动喜剧与韵文冒险高密度（拟声词全感叹）。
- 对话占比 >40% 的书（如《小象小猪》《石头汤》）依赖声音表演，旁白退居其次。

### 5.3 高频实词覆盖率

- 韵文/认知类：top10 实词覆盖率 25–40%——核心名词应复现 ≥6 次。
- 叙事类：覆盖率 8–15%——依赖情节推进而非词汇重复。

## 六、拟声词总库（按场景归类，可直接选用）

- **行进/触感**：Swishy swashy / Splash splosh / Squelch squerch / Stumble trip / Crunch / Tap / SCRUNCH / SCRATCH / THUMP / BONK / PLUNK / WHIFF / WHUMP
- **动物叫声**：Beep / Croak / Baaa / Moo / Oink / Cluck / Peep / Maaa / Neigh / Quack / Honk / Click clack moo / Woof / Meow / Hoot / Roar / HISS / BOING
- **巨响/惊讶**：BOOM / CRASH / POP / ZAP / BEEP / HONK / WHOOSH / SPLASH / ROAR / GLUG / PLOP / SPLAT
- **情绪/机械**：Ahhhh / Yippee / Oh-oh / Waaaa / Hooray / Vroom / Buzz / Ding / Clang

---

## 七、对标流程

1. 定体裁 → 查「三、分体裁基准」锁定字符量/句长/副歌/无字页区间；
2. 定年龄 → 查「5.1 句长分档」锁定平均句长；
3. 写完 → 自测各指标（字符量、平均句长、副歌次数、无字页位置）；
4. 任一指标越界 20% 以上 → 回到对应原则修正（循环递进 / 节奏呼吸 / 高频词）。
