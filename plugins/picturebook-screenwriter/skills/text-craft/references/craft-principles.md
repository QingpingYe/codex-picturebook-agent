# 儿童绘本文字创作方法论

> 定位：绘本文字创作的**核心创作观与原则层**。供编剧创作的立意参考，跨体裁、跨项目恒定。
> 配套：`technique-cards.md`（技法细则）｜`craft-baselines.md`（数值护栏）｜`preflight-checklist.md`（自检）
> 说明：本文所述原则与数值为**体裁级通用基准**——文学工艺层的统计与惯例。凡涉及具体项目的页数、蓝思、词量等参数，一律以运行时加载的项目内容规格为准，本文不提供项目参数。

---

## 核心创作观（先立三观，再谈技巧）

1. **绘本是"读给别人听"的文学**。文字必须经得起朗读：可预测、有节奏、能跟读。判断标准是"成人读两遍，孩子能接出下一句"。
2. **文字只讲一半故事**。画面承担情绪、细节、伏笔与信息量，文字负责节奏、声音与悬念。写文字时同步设计"画面接管点"。
3. **重复不是偷懒，是教学**。儿童通过重复获得掌控感、通过微替换完成学习。所有结构性重复都服务于"可预测性 → 意外打破"的认知循环。

---

## 一、结构原则：骨架决定成败

### 循环递进原则

叙事主干的通用形态是「循环 + 递进 + 打破」：
- **循环**：同一组句式/事件重复 3-8 次。3 次构成"三次法则"的最小完整结构；5-6 次适合冒险收集型；8 次以上需逐次递减以维持新鲜感。
- **递进**：每次循环只换 1-2 个变量，且递进维度明确（规模升级：little→big→huge；情绪升级：不安→害怕→崩溃；代价升级）。
- **打破**：最后一轮循环必须偏离模式——这是全书的转折点，也是儿童最兴奋的时刻。打破后紧接解决。

### 节奏呼吸原则

全书文字量是一条曲线，不是常数：
- 高潮页文字最少（往往一两行），让画面与心跳接管；
- 铺垫页可以放宽，但单页仍以不超过 40 词为宜（低幼减半）；
- 全书安排 2-6 个无字跨页（Silent Spread），放在情绪顶点、狂欢、变身处；睡前书可省略。

### 翻页张力原则

页与页的交界是绘本独有的叙事杠杆：
- 每 3-5 页设一个翻页钩子：未完成句、问句、悬念词（"直到有一天……"）；
- 最高级的钩子是把词断在页间（感叹词断成两半、名词断在音节中间），翻页即"引爆"；
- 第一转折点与高潮前必须有强钩子。

### 首尾回环原则

结尾应与开头成镜像：开篇定调句在结尾重现但语义翻转（"我讨厌我的脖子"→"我为我们的脖子骄傲"；"我们不怕"→"再也不去了"）；或用"倒放"一次性回顾全部旅程（把已克服的障碍按相反顺序快速扫一遍），制造完成感与安全感。

## 二、语言原则：为耳朵写作

### 高频词优先原则
- 正文只用 3-8 岁口语高频词；每个"难词"都是特意的香料：首次出现必须在重复语境中出现 2-3 次，且必须有画面直接支撑（不需文字解释）。
- 目标蓝思值通过句长与词汇双通道控制，而非回避难词。

### 声音设计原则
- **拟声词**是动词、音效、情绪三合一：每本精选 2-10 个，同一拟声连写三次成行是标准用法；拟声词库按"行进/动物/巨响/情绪"四类管理。
- **音韵游戏**（头韵、内韵、自造复合词）服务于朗读快感；自造词必须"可拆解猜测"（prickly+perch 式），不可纯乱造。
- **慢写拆词**（s-l-o-w-l-y）与大写爆发页（情绪顶点整页大写）是排版级的声音技法。

### 微替换原则
重复句式只替换承载信息的 1-2 个词，且替换词保持相同音节数。被替换的词就是该页的教学焦点——儿童的"找不同"游戏。

## 三、叙事原则：弧线与情绪

### 五种母弧线（按主题选用其一）

| 弧线 | 结构 | 适用主题 |
|---|---|---|
| 恐惧智取 | 制造威慑→威慑反噬→借力反杀 | 勇气、机智；主角武器必须是语言/计谋 |
| 自我接纳 | 厌恶特征→遇羡慕者→互相欣赏→同句翻转 | 外貌、天性；开篇句在结尾原位翻转 |
| 焦虑化解 | 灾难化清单（荒诞升级）→亲验/同伴→反转 | 入学、黑暗、第一次；不说教 |
| 秩序倒转 | 日常秩序被荒诞打破→一本正经自洽→回归+留钩 | 反叛、幽默；公文腔讲荒诞事 |
| 平行视角 | 同一对象多视角平行观察→汇合 | 认知、启蒙；文字极简，认知负荷全给画面 |

补充弧线见 `technique-cards.md` 的「五母弧线卡」（含线性冒险、生活切片等变体）。

### 情绪具象原则

抽象情绪必须映射为儿童可感的具体物象（星、云、雪、气球、火山），并配"命名句"收束（"This is when my heart is mad."）——命名情绪本身即是情绪教育的核心动作。每跨页处理一种情绪。

### 解决原则
- 主角解决冲突靠**智慧、语言或同伴协作**，不靠成人拯救、运气或说教；
- 和解与转变由主角主动完成，成人角色至多是引路的提问者。

## 四、声音关系：对话与读者

### 不对称对话原则

两个角色的话轮长度刻意悬殊：长句方暴露性格（狡辩、焦虑、唠叨），短句方掌控局面。"少即是权力"——话最少的角色往往是最终赢家。

### 读者入戏原则

打破第四面墙，把读者设为被委托者/守门人/裁决者：书中角色越"失控"，孩子越有掌控感。结局必须把最终裁决权交还读者（"还记得我说的吧？"）。

### 书信体原则

用信件、字条、告示推进剧情：自带"称呼-正文-落款"三段格式，第三次重复即可预测；每封信=一个角色的完整人格速写。适合多角色、多声部故事。

## 五、图文分工：文字的克制

### 留白交接原则

信息量的一部分**只放在画面里**（标牌、标签、道具细节），正文绝不解释；写正文时同步标注"此处画面应含 XX"作为插画指令。伏笔藏在画面里、正文只字不提，翻页后由情节回收——这是"展示而非讲述"的工程化实现。

### 极简分档原则

按类型控制文字密度：认知/睡前书每页 ≤1 句；标准叙事按体裁区间；超过桥梁书门槛即已跨入章节书范畴，不再是绘本节奏。体裁级区间见 `craft-baselines.md`。

## 六、类型基调：先定基调再下笔

| 体裁 | 语言基调 | 结构必备件 |
|---|---|---|
| 睡前安抚 | 短句、韵脚、渐进安静 | 固定场景循环 + 告别清单 + 归于睡眠 |
| 冒险韵文 | 副歌、拟声、可 chant | 3-6 次循环 + 障碍清单 + 惊险-安全往返 |
| 互动喜剧 | 对话体、短句、尖叫排版 | 对读者喊话 + 情绪爆发页 + 开放结局 |
| 情绪教育 | 第一人称、比喻、命名句 | 情绪意象库 + 命名句 + 同伴和解 |
| 认知概念 | 极简、可预测、音韵游戏 | 单一认知目标 + 图像承担信息量 |
| 荒诞幽默 | 正经腔讲荒诞事 | 书信/公文格式 + 画面伏笔 + 尾页小反转 |
| 成长仪式 | 第二人称预言式韵文 | "You'll…"句式 + 低谷段 + 结尾拥抱 |
