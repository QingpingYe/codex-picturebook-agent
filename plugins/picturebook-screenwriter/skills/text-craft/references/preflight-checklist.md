# 创作检查清单：绘本文字写作前 / 中 / 后自检

> 用法：三个阶段各过一遍。□ 全勾才算完稿；任一 ✗ 标注原因并回到对应技法卡修正。
> 配套：`craft-principles.md`（方法论）｜`technique-cards.md`（技法细则）｜`craft-baselines.md`（数值护栏）
> 说明：清单中的数值为体裁级通用门槛。凡与运行时加载的项目内容规格冲突，**以项目规格为准**。

---

## 阶段一：写作前（定盘子）

### 1.1 定位三问

- [ ] **体裁**明确？（睡前/冒险韵文/互动喜剧/情绪教育/认知/荒诞幽默/成长仪式/民间故事/桥梁书 → 查 `craft-baselines.md` 的「分体裁基准」锁定字符量/句长/副歌/无字页区间）
- [ ] **目标年龄**明确？（锁定句长档：2-4 岁 ≤5.5 词/句；4-6 岁 6-8；5-8 岁 8-12）
- [ ] **母弧线**选定？（恐惧智取/自我接纳/焦虑化解/秩序倒转/平行视角/线性冒险/生活切片 → 查 `technique-cards.md` 的「五母弧线卡」）

### 1.2 骨架预设

- [ ] 副歌/循环句式已写出？循环次数 3-8 次已定？末次打破点已标？
- [ ] 递进维度已定？（体型/情绪/代价 三选一）
- [ ] 高潮页位置已定？该页字数预算 ≤2 行？
- [ ] 无字页位置已排？（情绪顶点 1-3 处；睡前书除外）
- [ ] 开篇起手式选定？（书名副歌/呼唤读者/设定宣言/危机预告 → `technique-cards.md` 的「开篇四式卡」）
- [ ] 结尾收法选定？（镜像句/日常回归+微变/开放钩 → `technique-cards.md` 的「尾页三式卡」）是否需要成环？（「圆环结构卡」）

### 1.3 主题安全

- [ ] 主角解法 = 自己的智慧/语言/同伴协作？（不靠成人拯救、运气、说教）
- [ ] 情绪基调明亮正向？挫败后必有出口？
- [ ] 若含"害怕的东西"：是否已命名拟人化（`technique-cards.md` 的「恐惧拟人命名卡」）？驱赶方式是否为儿童身体动作？

## 阶段二：写作中（每页过一遍，逐页自检）

### 2.1 逐页硬指标

- [ ] 本页字数在体裁档内？（睡前 ≤15 词、标准叙事 ≤40 词、桥梁书 ≤600 词/章）
- [ ] 是否本页是高潮/转折 → 文字 ≤2 行？
- [ ] 副歌出现时：是否只替换了 1-2 个信息词？替换词音节数与原句对齐？
- [ ] 递进序列中：动词/形容词是否与规模同步升级？

### 2.2 朗读测试（每个跨页）

- [ ] 读出声一遍：舌头不打绊？
- [ ] 读出声两遍：孩子能否接出下一句/下一个词？
- [ ] 韵脚行末词是否押韵？中文稿叠词是否自然？

### 2.3 图文分工

- [ ] 本页是否有"只属于画面"的信息？（标签/背景道具/表情细节）→ 正文是否避免了复述？
- [ ] 伏笔道具是否在画面指令中标注？（`technique-cards.md` 的「画面伏笔卡」）
- [ ] 是否需要"（本页无文字）"+ 画面意图说明？

### 2.4 声音

- [ ] 拟声词是否在预算内（全书 2-10 个）？本页用量是否克制（≤2 个）？
- [ ] 对话双方话轮是否不对称（性格鲜明）？
- [ ] 互动书：读者是否收到了具体身体动作指令（抖书/晃手指/找一找）？

## 阶段三：写作后（全书终检）

### 3.1 量化复测

- [ ] 全书字符量落在体裁区间？（极简 <1200 / 标准 1500-6500 / 桥梁 >10000）
- [ ] 平均句长落在目标档？（越界 20% 回炉）
- [ ] 副歌种数与最高频重复次数达预期？（韵文书 ≥3 种、频次 5-9）
- [ ] 无字页数量与位置正确？（2-6 页、位于情绪顶点）
- [ ] 开篇含书名？（韵文书必须；纯叙事书可豁免）

> 本阶段可由 `craft-benchmark-check` 技能自动产出指标报告，逐项对标。

### 3.2 结构终检

- [ ] 末次循环是否打破模式？打破后是否紧接解决？
- [ ] 翻页钩子：每 3-5 页一枚？第一转折点+高潮前两处强钩齐备？
- [ ] 结尾与开篇成镜像/成环？同句不同义？
- [ ] 全书读完后是否有"再读一遍"的冲动（成环书强制项）？

### 3.3 语言终检

- [ ] 每个难词：画面支撑？重复 2-3 次？
- [ ] 自造复合词 ≤3 个且可拆解？
- [ ] 慢写/大写排版 ≤2 处且用在情绪顶点？
- [ ] 语气占比合理？（问句驱动的书：每循环至少一问）

### 3.4 情感与安全终检

- [ ] 无说教句（教训由情节自己说出）？
- [ ] 无负面情绪堆叠（每种负面情绪 ≤2 页即给出路）？
- [ ] 冲突无身体暴力（追逐/误会有，伤害无）？
- [ ] 结尾情绪收点为：安全/温暖/欢笑 三者之一？
- [ ] 词汇与情景无恐怖暗示？

### 3.5 提交物完整性

- [ ] 逐页文字 + 无字页画面意图 + 画面伏笔指令（`technique-cards.md` 的「画面伏笔卡」「边框信息卡」）+ 插画接管点标注齐全
- [ ] 附：量化指标自测结果（字符量/句长/副歌次数/无字页位置）
- [ ] 附：母弧线与体裁标签

## 快速版（时间紧张时的 10 项最低门槛）

1. □ 体裁与年龄定位写入文档头
2. □ 副歌/循环结构存在且末次打破
3. □ 高潮页 ≤2 行
4. □ 开篇 3 行内有钩子；结尾与开篇镜像或成环
5. □ 平均句长在年龄档内
6. □ 拟声词 ≤10 个
7. □ 无字页 2-6 页置于情绪顶点（睡前书可 0）
8. □ 解法靠主角自己，无说教
9. □ 难词全部有画面支撑
10. □ 朗读两遍不打绊、能预测
