# 文字工艺库（Text Craft Library）

## 定位

本技能承载儿童绘本文字创作的**体裁级通用工艺**——文学层面的原则、技法、数值护栏与自检清单。它回答的是“**写得像不像绘本**”，与具体项目的世界观、规范、红线和数值参数互补，不互相替代。

工艺层是**跨系列、跨项目、跨产物类型恒定**的——它描述的是儿童绘本这一文学体裁的通用规律（朗读性、循环递进、翻页张力、声音设计、母弧线、图文分工），不随项目变化。

## 调用契约

本技能是 Codex 最小版中的单一工艺权威副本，入口工作流在创作、产出前自检和质检阶段共享引用，不复制内容。

## 与项目权威知识的边界（分层判定）

工艺基准与项目权威**不是同一层的判据**，判定级别不同，不得互相覆盖：

| 判据来源 | 性质 | 判定级别 |
|---|---|---|
| 项目权威（世界观红线 / 纠正登记册 / 内容规格） | 项目硬约束 | FAIL，阻断 |
| **工艺基准（本技能）** | **体裁级通用基准** | **WARN 起步；越界容忍度后升 FAIL** |
| 经典作品惯例（技法卡片例证） | 参考惯例 | 不判定，仅供看齐 |

**冲突消解**：工艺基准与项目权威冲突时，**一律以项目权威为准**——工艺基准只提供“看齐参考”，不覆盖项目规范。例如项目的句长规格若与体裁通用档位不同，执行以项目规格为准，工艺偏离只作提示。

## 不含项目参数（合规声明）

本技能及其四份参考**不含**任何系列名、项目名、IP 或角色专名，**不含**任何项目的页数、蓝思、词量等参数。

参考文件中的数值均为**体裁级通用基准**——来自经典作品的文学工艺统计，跨项目恒定。凡涉及项目参数，一律以用户会话中明确给出的项目内容规格为准；`craft-benchmark-check` 的阈值来自 [references/craft-baselines.md](references/craft-baselines.md) 的「机读基准块」，而非项目配置。

## 降级规则

- 四份参考缺失（安装不完整）时，按“工艺层未加载”显式标注后继续，不阻塞创作——工艺层是增强而非前置条件。
- 机读基准块解析失败时，`craft-benchmark-check` 回退脚本内置的同源默认值，并标注实际使用的阈值来源。
