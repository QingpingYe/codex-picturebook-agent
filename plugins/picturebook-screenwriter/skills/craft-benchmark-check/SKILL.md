# 文字工艺量化自测（Craft Benchmark Check）

## 定位

本技能是 [text-craft](../text-craft/SKILL.md) 工艺层的**可执行出口**：工艺方法论里凡是能计数的部分，不应停留在"写完自己看看"，而应由确定型脚本复测。它回答的是"各项工艺指标是否落在体裁基准内"，与回答"是否触犯项目红线"的廉价代理互补——两者并列进入产出前自检。

在 Codex 最小版中，入口工作流在剧本自检、产出前自检和质检阶段复用本技能；它提供确定型指标，语义判断仍由主会话完成。

## 阈值来源（单一权威）

阈值来自 [craft-baselines.md](../text-craft/references/craft-baselines.md) 的「机读基准块」——脚本按以下顺序定位，命中即用：

1. 命令行 `--baselines <路径>` 显式指定；
2. 同包自动定位 `text-craft/references/craft-baselines.md`；
3. 前两者不可用时回退脚本内置的同源默认值，并在报告中标注"阈值来源：内置兜底"。

**不要在本技能内另存一份基准副本**——基准的唯一权威是 `text-craft` 的基准文件，两处各写一份必然漂移。

## 执行

```bash
python scripts/craft_benchmark.py \
    <逐页脚本.md> \
    [--genre <体裁>] [--age <目标年龄>] \
    [--climax-pages <页号,逗号分隔>] [--title-word <书名关键词>] \
    [--baselines <基准文件路径>] [--json <输出.json>]
```

**输入格式**：markdown 逐页脚本表。脚本自动识别首列为页码、含 `Text`（或"英文"）列的表格；同步识别「分页大纲」表以定位高潮页。头部元信息（目标年龄 / 文体 / 体裁）自动解析，其中文体 / 体裁用作 `--genre` 的默认值。

**参数说明**：

| 参数 | 用途 |
|---|---|
| `--genre` | 指定体裁以匹配分体裁基准；未指定时取脚本头部的文体 / 体裁字段；两者皆无则只输出指标不做区间判定 |
| `--climax-pages` | 高潮页号（逗号分隔）。未指定时尝试从分页大纲的叙事功能列自动识别 |
| `--title-word` | 书名关键词，用于开篇复现检查；未指定时取脚本标题 |
| `--json` | 额外输出结构化结果，供质检报告引用 |

Windows 上若 `python` 指向 Microsoft Store 存根，先定位可用解释器再执行；不要因为命令失败而静默跳过检查。

## 十五项指标与判定口径

| # | 指标 | 计算方式 | 判定 |
|---|---|---|---|
| 01 | 全书字符量（去空白） | 非无字页正文拼接后去除空白统计 | 体裁区间 |
| 02 | 平均句长（词/句） | 句边界切分后的词数均值 | 目标年龄档 |
| 03 | 副歌句式种数 | 规范化行出现 ≥3 次且 ≥2 词者计为一种 | 韵文 / 认知 / 睡前类有下限 |
| 04 | 最高频重复行次数 | 规范化行的最大出现次数（附强度分档注） | 标准强度区间 |
| 05 | 无字页数量 | 文本列为空或含无字标记者 | 体裁区间（睡前书可为零） |
| 06 | 拟声词命中总数 | 内置拟声库匹配；另报连写三次组数 | 体裁预算 |
| 07 | 高潮页文字行数 | 高潮页正文按行计数 | 不超过上限 |
| 08 | 翻页钩子密度 | 页末问句/悬停省略/破折号三型候选页，算最长无钩连续页数；无字页重置计数、末页豁免 | 间隔上限（保守下限，只 WARN） |
| 09 | 单页拟声词用量 | 逐页不同拟声词种数（连写三次算 1 个） | 单页上限 |
| 10 | 副歌末段打破 | 最高频行在末四分之一页原样出现即报；成环收尾（末页复现开篇副歌）豁免 | 有副歌即判 |
| 11 | 无字页位置 | 以分页大纲高潮/转折段为情绪顶点代理，静默页落在外即报 | 顶点段内即 PASS |
| 12 | 开篇复现书名 | 首正文页与书名关键词比对 | 韵文类应为是，叙事类可免 |
| 13 | 首尾回环度 | 首末页实词重合占比（去停用词） | 循环类结构应强回环 |
| 14 | 慢写/大写排版处数 | 逐字母断开模式 + 整行大写计数 | 不超过上限 |
| 15 | 形态分档（无体裁时兜底） | 字符量对比极简型/标准绘本/桥梁书区间 | 仅记录 |

**判定三档**：落在区间内 → PASS；越界但在容忍度内 → WARN；越界超过容忍度 → FAIL。容忍度取自基准块的 `tolerance_pct`。**退出码**：有 FAIL 返回 1，否则 0（供流程判断）。

**体裁基准缺失时**：跨体裁通用项（钩子密度/单页拟声/副歌末段/无字页位置/高潮页行数/排版/回环）照常判定，分体裁项降为形态分档记录，不做区间判定，并提示可用 `--genre` 指定——不假装有基准。

## 能力边界（不得夸大）

- **只覆盖可计数的维度**。语义维度（朗读体验、图文互补、情绪具象、说教倾向）不在射程内，仍由入口工作流与人工朗读测试承担。
- **副歌检测基于行级规范化重复**，对跨行副歌、变体副歌（微替换后）识别有限——这类由 LLM-judge 补充判定。
- **自造复合词未纳入自动检测**（自然语言难以零假阴性识别），列于人工自检项；机读基准块不为其设键。
- **无字页识别依赖显式标记**（文本列为空或含"本页无文字"类标记）。稿中未标记的无字页不会被识别——这是刻意的零假阴性取向：宁可漏报也不臆测。
- **翻页钩子密度是保守下限**：候选只含页末问句/悬停省略/破折号三型（技法卡 C1.4 物品揭晓型与句中断词不可正则检出），只升 WARN 不升 FAIL。
- **无字页位置以大纲叙事功能为情绪顶点代理**：无分页大纲且未指定高潮页时该行 INFO 不判；特殊用途（跌落段等）交入口工作流复核。
- **成环收尾是技法不是未打破**：末页复现开篇副歌（C7.3）已豁免，打破信号只看末四分之一其余页。

## 输出耦合

- 报告直接进入「创作决策说明」附页（工艺指标自测表），并随草稿呈现给用户；
- 入口工作流在产出前自检阶段以本报告作为廉价代理的工艺分支结果；
- 质检阶段读取 `--json` 输出的指标值作为实际值列。
